# ML Learning

Notebooks from learning machine learning basics, using my thesis data on fiscal consolidation and productivity.

## Notebooks

| # | Notebook | Topic |
|---|----------|-------|

The notebooks run in Google Colab. Each one asks you to upload `panel_master.csv`, a country-year panel. The data is not included in this repo.
